# Gemini CLI Tools

Este directorio contiene configuraciones, prompts y extensiones para el Gemini CLI.

## Estructura
- `configs/`: Archivos de configuración.
- `prompts/`: Prompts y plantillas personalizadas.
- `extensions/`: Extensiones locales.

## Comandos rápidos
- `gemini login`: Iniciar sesión.
- `gemini config set model gemini-1.5-pro`: Configurar modelo por defecto.
