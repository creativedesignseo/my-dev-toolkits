## Appendix B — Methodology

This audit was performed by the [`saas-audit` skill v0.1](https://github.com/...). It spawned {{N}} specialist agents in parallel:

- **Architecture** — repo structure, routes, layers, critical flows
- **Security** — auth, RLS, CORS, secrets, XSS, privilege escalation
- **Payments** — {{payments_provider}} end-to-end, webhooks, idempotency
- **Database** — schema, RLS, RPC, migrations, atomicity, referential integrity
- **Admin** — admin routes, permissions, destructive actions, audit trail
- **UI/UX** — design system, components, responsive, checkout trust
- **QA Functional** — E2E flows, edge cases, error handling, accessibility
- **SEO/Performance** — metadata, OG, bundle, Core Web Vitals
- **Deploy/Production** — env vars, headers, redirects, CI/CD
- **Stack/Modernization** — dependencies, versions, technical debt
- **Legal/Compliance** — GDPR/LOPDGDD, third-party ToS, DSA, consumer law

Each specialist outputs structured findings in YAML. The reporter deduplicates, scores per the algorithm in `helpers/scoring.md`, and produces this consolidated document.

## Banner colors

In terminal output, use ANSI codes (truthful — if the terminal doesn't support them, the chars are still readable):

- Critical: red
- High: yellow
- Medium: blue
- Low: dim
- Recommendation: gray

Filled bars: green for 80%+, yellow for 50-79%, red for <50%.

## File writing rules

- **Always** write `AUDIT_REPORT.md` at the project root (overwrite if exists, preserving previous as `AUDIT_REPORT.{{timestamp}}.md` if score regressed vs last audit).
- **Always** create/update `.saas-audit/history.json`.
- **Always** add `.saas-audit/` to `.gitignore` if a `.gitignore` exists and doesn't already include it.
- **Never** modify any other file in the repo.

## Failure handling

If a specialist agent times out or returns unusable output:

1. Log a warning in the report: `> ⚠️ The {{area}} specialist did not return parseable findings. Re-run with `/saas-audit --focus={{area}}` for a focused re-audit.`
2. Score that area as `weight` (no penalty applied — but flag uncertainty).
3. Don't fail the whole audit — produce a partial report.
